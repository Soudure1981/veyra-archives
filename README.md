# Veyra Archives (Cogitateur)

Dépôt prêt à publier sur **GitHub Pages**.

## Mise en ligne rapide
1. Pousse ce dossier dans un repo GitHub (ex: `veyra-archives`)
2. GitHub → **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` / Folder: `/ (root)`

Le site sera accessible via l'URL GitHub Pages fournie.

## Structure
- `index.md` : page d’accueil
- `archives/` : documents .md
- `_layouts/default.html` : cadre cogitateur
- `assets/style.css` : skin vert/noir
